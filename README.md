# Interactive Electrochemistry Simulator  
### Zimmer & Peacock • Version 1.3.0

This repository contains an interactive, browser‑based electrochemistry simulator built using Streamlit.  
It is designed for scientific outreach, education, and rapid exploration of electrochemical theory.

The first implemented model is the **Cottrell chronoamperometry simulation**, with additional simulations planned for future releases.

---

## 🚀 Features

- Sidebar‑based parameter control  
- Electrode area in mm² (ZP 501 default: 1.96 mm²)  
- Concentration input in mM  
- Dual‑axis plot (Current + Charge)  
- Downloadable PNG plot  
- ZP branding (logo + footer)  
- Modular tab layout for future simulations  
- Clean, professional UI suitable for demos and conferences
